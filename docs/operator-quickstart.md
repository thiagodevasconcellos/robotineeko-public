# Operator Quickstart

This quickstart explains the intended high-level path through the product.

## Normal flow

1. Start in `Strategy` to define or inspect a trading rule.
2. Move to `Backtester` to evaluate it with explicit market and cost assumptions.
3. Use `Results` to inspect trade distribution, drawdown, and net outcome.
4. Use `Research` to compare variants and decide whether an idea deserves promotion.
5. Use `Trader` when a configuration is mature enough for runtime monitoring.

## Demo policy

The live product supports a guest-safe showcase mode. Public sessions can inspect the system shape without being allowed to mutate durable state or trigger heavier operational actions.

## Documentation inside the product

Robotineeko includes a built-in documentation surface. The same product story can be read inside the app, not only in GitHub.
