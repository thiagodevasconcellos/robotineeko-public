# Public Surfaces And Access Modes

Robotineeko has more than one surface and more than one access policy, so it should not be judged as a single static page.

## Main route

The main route is the desktop console. It is the broadest product surface and contains the chart, the main console tabs, and the authenticated workflow.

## Mobile route

The product also includes a phone-first monitoring route for trader follow-up away from the desktop console.

## Guest access

The live product has a curated guest mode. That mode exists so reviewers can inspect the system honestly without being granted heavy runtime controls or state-changing permissions.

Guest sessions can inspect:

- chart and console structure
- curated documentation
- showcase-safe research and neural surfaces

Guest sessions cannot do things like:

- persist workspace state
- run heavy jobs
- operate live runtime controls

## Public repository versus live system

This repository mirrors the real product structure, but it does not publish every route or every internal surface. Restricted business surfaces remain outside the public snapshot.
