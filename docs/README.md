# Documentation

This folder mirrors the guest-safe documentation set that is available inside
the live Robotineeko product.

It exists so a recruiter or technical reviewer can understand the product
without needing to discover the in-app docs on the live site first.

## Scope note

These documents are intentionally public-safe. They explain product structure,
workflow, and engineering decisions, but do not expose runtime secrets, user
data, internal host configuration, or restricted business surfaces.
